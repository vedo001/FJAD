01 / ABOUT THE GAME

ชีวิต Data Analyst แบบที่ไม่ได้มีแค่กราฟสวย ๆ

เกมนี้เน้นอารมณ์ของ “งานจริงวันแรก” ทั้งเรื่องข้อมูล ปัญหา deadline และการตัดสินใจในงาน

01

โจทย์จากคนทำงานจริง

คุณไม่ได้รับ requirement ที่สมบูรณ์แบบเสมอไป ต้องอ่านสถานการณ์ ตีความ และเลือกว่าจะจัดการอะไรก่อน

02

ทำงานกับข้อมูลที่ไม่สมบูรณ์

เจอข้อมูลขาด ข้อมูลซ้ำ หรือโจทย์เปลี่ยนกลางทางได้เหมือนโลกจริง และคุณต้องหาทางไปต่อ

03

ตัดสินใจแล้วมีผล

เลือกผิดหรือเลือกช้าอาจกระทบเวลา พลังงาน ความไว้ใจของทีม และรูปแบบการเดินเรื่องของตัวละคร

02 / PLAYTEST FLOW

วิธีเข้าร่วมทดสอบแบบง่าย ๆ

เราออกแบบให้ผู้เล่นเข้าใจง่าย เข้าเล่นได้เร็ว และส่ง Feedback กลับมาได้ทันที

STEP 01

กดเข้าเล่นเกม

คลิกปุ่ม เข้าเล่นเกม จากหน้านี้ แล้วเริ่มทดลองเล่นผ่าน Browser ได้เลย

STEP 02

จดจำ User ID

หากเกมแสดง User ID ของคุณไว้ ให้นำมาใส่ในฟอร์ม เพื่อให้เราตรวจสอบ session ได้ตรงจุด

STEP 03

ส่ง Feedback กลับมา

บอกเราทั้งสิ่งที่ชอบ สิ่งที่งง ความยาก จุดไม่สมดุล หรือ bug ที่พบระหว่างเล่น

WE NEED TESTERS

เจออะไรแปลก ๆ บอกเราได้เลย

Bug, ความยาก, UX, เนื้อเรื่อง หรือความรู้สึกหลังเล่น — ทุก Feedback ช่วยให้เกมดีขึ้น และช่วยกำหนดทิศทางเวอร์ชันถัดไป
